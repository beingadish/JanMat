# JanMat

JanMat (People's Opinion) is a Rust-first civic opinion platform scaffold.

This repository now contains the implementation baseline for Phase 0:

- Rust workspace with modular crates
- Shared `janmat-types` primitives (ULID + anchor hashing)
- Chain/pallet scaffolding for namespace, voting, identity, moderation, governance
- Axum API service skeleton with `/health`
- Frontend crate placeholder and onboarding page module path
